# 🌸 RE-TheSeason – font Việt hóa "The Season"

**RE-TheSeason** là dự án Việt hóa font chữ "The Seasons" – một kiểu chữ serif thanh lịch, thủ công, mang hơi hướng thư pháp hiện đại. Font được tối ưu để sử dụng trong thiết kế đồ họa, trình bày văn bản nghệ thuật, in ấn, và các ứng dụng sáng tạo khác.

---

## 🖋️ Giới thiệu font "The Seasons"

Font **The Seasons** được thiết kế bởi **Elena Genova** từ xưởng chữ **My Creative Land**, nổi bật với:

- ✨ Phong cách serif mềm mại, độ tương phản cao
- 🎨 Lấy cảm hứng từ thư pháp và chữ viết tay
- 🌍 Hỗ trợ đa ngôn ngữ, bao gồm tiếng Việt
- 📐 Phù hợp cho tiêu đề, logo, poster, video, in ấn và web

> Font gốc có 6 kiểu chữ:  
> Light, Light Italic, Regular, Regular Italic, Bold, Bold Italic

## 📦 Cài đặt

### 1. Tải font

Truy cập kho mã nguồn:  
🔗 [github.com/nguyentutiensinh/RE-TheSeason](https://github.com/nguyentutiensinh/RE-TheSeason)

Tải file `.ttf` hoặc `.otf` trong thư mục chính hoặc bản phát hành.

### 2. Cài đặt vào hệ thống

#### 🪟 Windows

- Nhấn chuột phải vào file `.ttf` → chọn **Install**
- Hoặc copy vào thư mục: `C:\Windows\Fonts`

#### 🍎 macOS

- Nhấn đúp vào file `.ttf` → chọn **Install Font**
- Font sẽ xuất hiện trong Font Book

#### 🐧 Linux

- Copy font vào thư mục `~/.fonts` hoặc `/usr/share/fonts`
- Chạy lệnh `fc-cache -fv` để cập nhật
